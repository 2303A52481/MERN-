javascript is a single threaded synchronous programming language. it converts the static pages into the dynamic pages.
single threaded definition: only one task can be executed at a runtime
multiple threaded definition: multiple tasks can be executed at a runtime. example: java, python, c++
synchronous : line by line execution of code. the next line of code will be executed only after the previous line of code is executed.
asynchronous : the next line of code will be executed without waiting for the previous line of code to be executed. it allows multiple tasks to be executed at a runtime. example: setTimeout, setInterval, fetch, promises, async/await.
js by default synchrous but we can make it asynchronous by using callback functions, promises, async/await.
js is interpreted by default . both compiled and interpreted language. it is interpreted by the browser and compiled by the v8 engine in chrome.
